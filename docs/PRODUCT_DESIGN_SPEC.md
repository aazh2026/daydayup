# 智学中枢 · 上海初三 AI 提分操作系统产品设计文档（MVP 规格书）

> **产品核心策略**：路线 B（AI 提分操作系统）—— **一个学生，一个目标，一个提分闭环 · 7天验证一个学习策略**  
> **首期聚焦范围**：上海初三中考（全面覆盖 **数学、英语、物理、化学、语文** 五门中考核心学科）

---

## 一、产品定位与核心策略

### 1.1 路线选择：AI 提分操作系统 vs. AI 家教

| 对比维度 | 路线 A：AI 家教 | 路线 B：AI 提分操作系统（本产品采用） |
| :--- | :--- | :--- |
| **核心能力** | AI 讲解、答疑、出题 | 诊断 → 决策 → 规划 → 执行 → 独立验证 |
| **驱动模式** | 用户被动/主动提问 | 系统主动发现失分漏洞并动态排定提分任务 |
| **产品壁垒** | 易被通用大模型替代 | 深度绑定上海中考考纲、知识状态机、失分归因与边际提分决策 |

### 1.2 每周系统必须回答的五个核心问题

1. 学生目前最影响成绩的三个问题是什么？
2. 哪个问题最值得优先解决（边际提分效率最高）？
3. 每天具体应该学什么（严格控制在每日可用时间预算内）？
4. 学生是否真的掌握了（通过独立变式题与延迟复测验证）？
5. 下一周应该如何调整学习计划？

### 1.3 分阶段产品演进路线

| 阶段 | 产品形态 | 核心价值 |
| :--- | :--- | :--- |
| **V1：提分闭环（当前 MVP）** | 试卷诊断 + 7天学习计划 + AI训练 + 变式复测 | 证明能够帮助一名真实初三学生有效提分 |
| **V2：智能提分** | 知识追踪 + 自适应训练 + 动态规划 | 提升单位时间学习效率 |
| **V3：个性化学习系统** | 多学科知识本体 + 长期能力模型 + 多 Agent 协作 | 服务不同年级、不同地区、不同学生 |

## 二、六大核心业务模块设计

### 模块 01：考试诊断中心（MVP 核心入口）

**目标**：让系统真正知道学生“哪里不会”以及“丢失的分数是怎么丢的”。

#### 1. 数据输入方式

| 输入方式 | 具体内容 | 系统处理方式 |
| :--- | :--- | :--- |
| **成绩录入** | 各科成绩、满分、阶段目标、考试时间 | 建立与刷新学科成绩基线 |
| **试卷拍照 / 已识别文本试卷** | 多页试卷照片（JPG/PNG），或 AI 已识别文本解读、OCR 转录稿、`.txt`/`.md`/`.json` 解析后文本试卷 | 多模态视觉 OCR 或纯文本解析切分，自动过滤全对题目、提取失分题与前序解读事实，映射上海考纲与五维错因 |
| **错题拍照/录入** | 单道错题题干、学生作答、正确答案 | 错题识别、知识映射与归因 |
| **主动诊断微测** | 系统生成的小型验证题 | 为低置信度假设补充独立能力证据 |

试卷诊断（拍照 OCR / 文本解析）的七步流水线：
1. 识别或解析整份试卷中的每一道题（支持图片与纯文本/Markdown/JSON）；
2. 提取题目分值、学生作答过程及前序 AI 解读中的有效事实；
3. 识别教师批改结果与扣分标注（跳过明确得满分的正确题目）；
4. 判断失分题目考查的上海考纲知识点；
5. 判断学生可能的五维错误原因；
6. 将每道题映射到版本化知识本体并经人工校验台核对；
7. 统计各知识点与知识域的失分分布。

#### 2. 结构化错误归因规范（严禁简单将错题等同于不会知识点）

每道错题必须区分以下 **五类失分原因**：
- **知识问题**：不理解概念、定理或公式条件；
- **方法问题**：理解概念但不知道解题切入路径或辅助线模型；
- **计算问题**：会列式但移项、符号、通分或代数运算出错；
- **熟练度问题**：思路正确但耗时过长或书写规范（如化学条件/沉淀符号）遗漏；
- **审题问题**：看错题目隐含条件、否定词或限定范围。

每条诊断结论必须附带四个结构化字段：
- **证据（Evidence）**：来自哪次考试、哪一道题及具体作答表现；
- **判断（Analysis）**：具体的失分根因分析；
- **置信度（Confidence）**：`确定` / `较可能` / `待验证`（严禁仅凭单道错题武断下结论）；
- **验证方式（Verification Method）**：通过何种微测题或变式题加以确认。

#### 3. 自动元信息识别、多次考试建档与场次对比
- **AI 自动识别考试元信息与卷面分数**：上传试卷图像或 AI 已解析文本时，支持选定「自动识别」学科与「AI 自动识别」场次；服务端自动提取试卷头部的 **学科门类（`subject`）、考试名称（`examTitle`）、考试类型（`examType`）、考试日期（`examDate`）、卷面实得分/满分（`score`/`fullScore`）** 及置信度，并在人工核对抽屉中自动匹配或新建 `Exam` 场次，可一键勾选将卷面得分同步写入 `ExamResult` 成绩基线；
- **逐卷分析完整存档**：每份诊断确认后的试卷均在 `ExamPaper` 中独立留存元信息、AI 识别摘要、关联知识点 ID 列表、原始文本稿/卷面图像与绑定错题集（`examPaperId`），可在「考试诊断」场次卡片下直接展开回溯；
- **学科知识思维导图问题定位（`SubjectKnowledgeMindMap`）**：基于单份试卷或全科累计诊断数据，结合初中五门学科的四级知识本体树（`学科 → 知识板块 → 核心考点 → 细分能力子技能`），通过红/琥珀/绿/灰四态分支与图标标签在思维导图上直观标出失分问题点与关联子技能，并在右侧透视面板联动展示该节点的试卷原题证据、先修依赖漏洞链及一键教练入口；
- **场次切换与纵向对比**：诊断报告支持在「全部考试累计视图」与任意历史考试场次之间一键切换，自动展示该场试卷识别摘要、关联错题证据链及较上一次考试的成绩变化差值。

### 模块 02：提分规划中心（有限时间的最优分配）

**目标**：回答“现在最应该学什么，才能在有限时间内拿到更多分数”。

#### 1. 提分机会评估指标

| 指标 | 含义 |
| :--- | :--- |
| **失分空间（LostScore）** | 当前在相关题型与知识点中损失的分数证据 |
| **可恢复概率（RecoveryProbability）** | 经过针对性训练后掌握并转化得分的概率 |
| **学习成本（LearningCost）** | 达到目标掌握状态所需的预计学习小时数 |
| **考试价值（ExamWeight）** | 该知识点在上海中考中的考频与分值权重 |
| **先修依赖（Prerequisites）** | 是否依赖尚未掌握的前置知识点 |
| **证据可信度（Confidence）** | 当前判断是否具备充分试题证据 |

#### 2. 确定性排序模型

$$\text{ExpectedGain}_i = \text{LostScore}_i \times \text{RecoveryProbability}_i$$

$$\text{Priority}_i = \frac{\text{ExpectedGain}_i \times \text{Confidence}_i \times \text{ExamWeight}_i}{\text{LearningCost}_i} \times \text{PrerequisiteModifier}_i$$

**核心分配原则**：
- 不按学科分数高低机械分配时间，严格按**边际提分效率（单位时间预期提分）**排序；
- 例如：投入 2 小时可恢复 3–4 分的“分式基础计算”、“化学用语规范”，优先级显著高于需投入 8 小时仅提升 2 分的“二次函数压轴题”。

#### 3. 现实约束条件（确定性程序强约束，不交由 LLM 自由发挥）
- **每日基准可用时间**：默认 60 分钟（支持 30–120 分钟动态调整）；
- **学校作业量调节**：作业“较重”时自动下调 15% 负荷，“轻松”时可适度上浮；
- **学生疲劳程度调节**：疲劳度“高”时自动压缩当日任务量，避免制造抵触；
- **先修知识锁定**：若某知识点的前置先修知识处于 `未诊断` 或 `待学习`，自动降权并引导先修基础内容。

### 模块 03：学习任务中心（今日学习首页）

**设计克制原则**：学生打开产品无需面对复杂图谱与海量资料，只需明确“今天这 60 分钟做什么”。

1. 每日严格控制在 **最多 3 项任务**，总时长不超过当日有效预算；
2. 每个任务必须包含：**明确学习目标**、**预计耗时**、**步骤拆解**、**可验收结果**；
3. **未完成重排机制**：若当日任务未能完成，支持标记重排，由规划器重新分配至后续日程，**绝不简单累积到第二天**；
4. **连续失误降阶保护**：若同一知识点在练习中连续答错 $\ge 2$ 次，自动触发难度降阶并推荐回归先修知识点。

### 模块 04：AI 学习教练（任务驱动型教学 Agent）

定位为任务驱动的教学 Agent，而非开放式闲聊机器人，具备五种明确教学行为：

| 教学行为 | 核心职责 |
| :--- | :--- |
| **诊断** | 通过微问题识别学生对前提条件或概念的真实理解 |
| **讲解** | 按当前掌握状态分层解释核心概念与易错边界 |
| **示范** | 展示标准例题的分步拆解路径 |
| **引导** | 默认采用苏格拉底式逐级提示，让学生自己完成关键一步 |
| **评测** | 通过新题与变式题验证是否真正独立掌握 |

**教学交互规范**：
- **引导深度分级（Stage 0 → Stage 4）**：问已知条件 → 问调用知识点 → 一级方向提示 → 二级算式骨架提示 → 完整分步示范；
- **不机械拒绝给答案**：默认苏格拉底启发，同时界面显式提供 **“我需要看完整讲解”** 逃生通道；
- **严格控制讲解粒度**：单轮输出聚焦一个思维节点，避免长篇教材式刷屏。

### 模块 05：知识与错题管理（个人学习知识网络）

建设四类相互关联的长期数字资产，并支持多维整理与统计分析：

1. **试卷分析存档（ExamPaper Archive）**：每份诊断过的图像/文本试卷独立建档，完整留存考试场次、学科门类、卷面实得分/满分、识别题量与失分、AI 卷面摘要、关联错题集与原始文本/图像；支持在「试卷分析存档库」按学科/场次/输入形式/关键词检索，并在诊断后持续回溯该卷五维错因拆解与涉及知识点的最新掌握变化；
2. **知识点档案（KnowledgePoint）**：知识定义、先修知识、常见考法、高频易错点、关联题目与掌握状态证据链；
3. **错题档案（ErrorRecord）**：原始题干、学生作答、参考答案、五维错因分类、AI 诊断证据、学生订正心得、闭环复测状态；
   - **多维错题整理**：支持按 **学科、五维错因、订正闭环状态（未订正/已订正/待复测/已闭环）、考试场次、关键词搜索** 进行组合筛选，并支持按时间最新或失分从高到低排序；
   - **五维错因失分统计与高频重复漏洞识别**：自动汇总五大错因的题数与失分占比，并跨考试聚合重复出错的知识点排行，高亮“跨场次重复失分”的顽固漏洞。
4. **变式题档案（VariantQuestion）**：围绕错因生成四层递进题型：
   - 同类型基础题；
   - 改变数字或条件的变式题；
   - 改变表达方式的迁移题；
   - 延迟复测验证题。

### 模块 06：提分效果评估

严禁将 AI 估算的掌握率直接等同于真实提分，必须通过 **三层评估体系 + 掌握变化轨迹** 验证：

| 评估层次 | 评估内容 | 核心量化指标 |
| :--- | :--- | :--- |
| **第一层：学习过程** | 计划可执行性 | 任务完成率、累计有效学习分钟数、无提示独立作答率 |
| **第二层：能力变化** | 漏洞是否真修复 | 已验证修复知识点数（需通过变式或延迟复测）、变式题正确率、知识点掌握阶梯跃迁/回退轨迹（`MasteryTransitionEvent`） |
| **第三层：考试结果** | 是否转化为得分 | 全科历次考试成绩趋势对比矩阵（跨月考/期中/模考横向变化）、距离目标分差值 |

## 三、底层核心模型设计

### 3.1 上海初三知识本体层级

$$\text{学科} \longrightarrow \text{章节} \longrightarrow \text{知识域} \longrightarrow \text{知识点} \longrightarrow \text{子技能}$$

首期以课程标准与上海初三适用教材为依据，内置版本化人工审核知识树（全面覆盖数学代数/方程/一次函数/二次函数/几何辅助线/统计概率、英语词汇词转/时态从句/首字母阅读、物理压强浮力/动态电路/电功率实验、化学用语方程式/溶液计算/气体实验探究、语文文言实词迁移/现代文赏析与结构/作文审题立意）。

### 3.2 学生知识掌握状态机

摒弃单一百分比，采用严格基于作答证据的 **6 阶状态机**：

1. **未诊断**：尚无近期考试或微测证据；
2. **待学习**：已存在明确失分或错题证据；
3. **学习中**：正在接受诊断讲解或已完成部分基础引导；
4. **初步掌握**：同型基础题能够独立完成；
5. **掌握**：变式题或迁移题能够独立完成；
6. **稳定掌握**：经过延迟复测仍独立作答正确。

> **状态回退规则**：若后续测试再次失败或连续失误 $\ge 2$ 次，状态自动回退至 `学习中` 或 `待学习`。

## 五、系统架构与服务端 API 规范

采用 **确定性业务编排 + 专项 AI Agent** 混合架构（前端页面通过后端 Express `/api/*` 代理调用 Gemini 模型，不在客户端暴露密钥）：

### 5.1 服务端 API 端点

| 接口路径 | 方法 | 对应 Agent / 职责 | 关键输入输出 |
| :--- | :--- | :--- | :--- |
| `/api/health` | `GET` | 服务健康检查 | 返回 `{ ok: true }` |
| `/api/diagnose-paper` | `POST` | **试卷诊断 Agent** | 输入试卷图片 Base64、AI 已识别/解析后的纯文本或 `.txt/.md/.json` 文本内容、示例标识与学科提示（支持 `'自动识别'`）；输出 `detectedMetadata`（自动识别学科/场次/类型/日期/分数）、结构化逐题识别、五科知识点 ID 映射、五维错因与置信度 |
| `/api/coach/chat` | `POST` | **教学引导 Agent** | 输入知识点定义、掌握状态、苏格拉底阶段、对话历史与学生输入；输出精简引导回复、教学行为类型与快捷选项 |
| `/api/practice/generate` | `POST` | **练习生成 Agent** | 输入知识点、层级（基础/变式/迁移/延迟复测）；生成题目并执行答案内部验算（`verificationCheck`） |
| `/api/practice/evaluate` | `POST` | **评测归因 Agent** | 输入题干、标准答案与学生作答；返回正误判断、错因归类、反馈与后续训练建议，驱动前端状态机更新 |

## 六、MVP 五个核心页面与交互规格

| 页面 | 模块映射 | 核心交互闭环 |

## 七、重点质量指标与落地风险防线

### 7.1 质量验收指标

| 质量维度 | 核心指标 | 要求 |
| :--- | :--- | :--- |
| **学习计划约束** | 每日时间预算满足率 | 100%（实际任务总时长 $\le$ 调节后每日预算） |
| **题目答案质量** | AI 生成题答案与解析正确率 | 生成阶段强制输出 `verificationCheck` 验算依据 |
| **诊断严谨性** | 证据与置信度完整率 | 100% 诊断结论绑定试题证据，不凭单题武断定论 |
| **教学稳定性** | 讲解可逃生率 | 任意引导阶段均可主动切换完整分步讲解 |

### 7.2 关键防线（防失败设计）

1. **知识体系权威性**：采用人工编排的上海中考考纲结构化本体，不依赖大模型临场自由编造知识树；
2. **拒绝虚假提分指标**：提分报告严格区分“待学习 / 初步掌握 / 掌握 / 稳定掌握”，仅当变式题或延迟复测独立通过后才计入已修复漏洞；
3. **防学习负担失控**：每日任务硬性封顶 3 项，不做无止境错题抄写、不做焦虑式排行榜，打开即进入今日最值钱的学习闭环。

## 八、MVP 端到端验收测试用例

| 用例编号 | 场景 | 操作步骤 | 预期结果 |
| :--- | :--- | :--- | :--- |
| **TC-01** | 试卷拍照诊断闭环 | 进入「考试诊断」→ 点击载入示例数学试卷 → 点击「启动 AI 试卷诊断」 | 成功识别题目与失分，新增对应 `ErrorRecord` 并更新相关知识点 `MasteryRecord` 与 7 天排序 |
| **TC-02** | 约束变化触发重排 | 进入「提分规划」→ 将每日可用时间调为 45 分钟，作业负荷调为「较重」 | 实际每日排期预算立即缩减，7 天内每日任务总时长严格 $\le$ 调节后预算 |
| **TC-03** | 苏格拉底引导与逃生 | 进入「AI 教练」→ 回答诊断问题 → 点击「我需要看完整讲解」 | 教练按阶段引导后，点击完整讲解可立即切换为完整分步示范 |
| **TC-04** | 变式评测推进状态机 | 在「AI 教练」右区切换「变式题」→ AI 生成新题 → 提交正确答案 | 评测通过后，对应知识点状态机跃迁为 `掌握`，关联错题状态更新为 `已闭环` |
| **TC-05** | 连续失误降阶保护 | 连续两次提交错误作答 | `consecutiveErrors` 累计至 2，状态机回退至 `待学习`，出现降阶巩固与前置知识回归提示 |
| **TC-06** | 三层效果报告验证 | 进入「提分报告」查看过程/能力/成绩三层指标、历次考试对比矩阵与知识点掌握变化轨迹 | 过程指标、多场考试趋势与状态机升降阶轨迹实时同步 |
| **TC-07** | 多维错题整理与分析 | 进入「提分报告」→「错题整理与归因分析」，按考试场次、五维错因与订正状态组合筛选 | 展示五维失分占比与跨考试高频重复漏洞排行，可记录订正心得并直达变式复测 |
| **TC-08** | 自动元信息识别与试卷存档 | 进入「考试诊断」选择「自动识别」学科与场次，载入或粘贴含试卷头部的文本/图片并启动诊断，确认同步成绩基线后前往「提分报告」→「试卷分析存档库」 | 自动识别学科、场次名、考试类型、日期与卷面分数并匹配/新建场次；存档库留存完整摘要、五维错因、涉及知识点最新掌握状态及原始文本/图像 |
| **TC-09** | 学科思维导图标记试卷问题点 | 在「考试诊断」切换不同学科与具体试卷（或在「试卷分析存档库」点击「在学科思维导图上标记本卷问题点」），点击标红的考点或四级子技能节点 | 思维导图按「学科→板块→考点→子技能」四级结构以红/琥珀分支高亮标出本卷失分问题点；右侧透视面板展示关联错题证据、前置依赖漏洞提示及「进入 AI 教练针对性攻克」入口 |
